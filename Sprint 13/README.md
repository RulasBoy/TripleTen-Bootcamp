# Sprint 13 - Pronósticos y Predicciones

## Descripción

Sprint dedicado a la introducción al Machine Learning (ML) y pronósticos. Aprenderás los principios fundamentales del aprendizaje automático, cómo aplicar algoritmos comunes para hacer predicciones, y el proceso completo de desarrollo de modelos.

## Objetivos del Sprint

- Comprender cómo funciona, en términos generales, el aprendizaje automático
- Aprender qué tareas de negocios ayuda a realizar ML
- Aplicar algoritmos comunes de ML para hacer pronósticos
- Conocer los pasos típicos del desarrollo de modelos

## Proyecto Final

**Tema:** Predicción de pérdida de clientes (churn) para una cadena de gimnasios

**Descripción:** Proyecto completo que incluye todo el proceso de desarrollo de un modelo de ML, desde la exploración de datos hasta la evaluación y recomendaciones de negocio.
